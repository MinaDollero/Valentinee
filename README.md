# Valentine's React (Vite + TypeScript)

Simple interactive Valentine page built with React + TypeScript (Vite). No APIs or keys required.

Run locally:
1. npm install
2. npm run dev
3. Open the URL printed by Vite (usually http://localhost:5173)

Features:
- No button initially above Yes.
- No moves away on hover or click.
- After 4 attempts, angry state shows a cat-gun GIF.
- Clicking Yes shows the happy image.
- Floating hearts background.
- All images are loaded from public URLs.
